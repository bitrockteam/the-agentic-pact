# Security policy

The Agentic Pact is a documentation baseline, not a security product. If you find
a vulnerability in repository automation, a published artifact, or a process that
could expose private information, report it privately through the repository's
GitHub Security Advisories page:

<https://github.com/bitrockteam/the-agentic-pact/security/advisories/new>

Do not include secrets, personal data, or exploit details in a public issue. If
private reporting is unavailable, contact the maintainer through the GitHub profile
for [Voloire](https://github.com/Voloire) and include only the minimum information
needed to reproduce the problem.
