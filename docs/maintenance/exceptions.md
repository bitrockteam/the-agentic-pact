# Exceptions

An exception is a deviation from a C01-C12 control, explicitly authorized by the maintainer
for one concrete case. It does not change the baseline or extend to another system, action,
or date. Ask before the deviation and name the control and conforming alternative.

An exception without a row here does not exist. If work would violate a control and no row
authorizes it, stop and request a decision.

This public register intentionally records only generic governance. Case-specific exceptions
must be reviewed for publication separately and must not include credentials, private
environment details, or personal operational history.
