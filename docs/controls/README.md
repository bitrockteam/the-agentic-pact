# The twelve controls

These controls are the normative core of The Agentic Pact. They are local policy, not
requirements silently attributed to a vendor, protocol, or taxonomy. They apply to
agentic systems, tool-using workflows, multi-agent systems, delegated actions, and
bounded automations.

Choose the applicable operating profile before selecting tools or enabling effects. A profile
changes how a control is applied; it does not disable the control.

| ID | Control |
|---|---|
| C01 | Justified complexity |
| C02 | One accountable writer for each shared state |
| C03 | Independent, informed verification |
| C04 | Authority verified at entry and action |
| C05 | Proposal separated from commitment |
| C06 | Production through a bounded executor |
| C07 | Explicit identity and delegation |
| C08 | Credentials scoped to the intended recipient |
| C09 | Secrets outside unconstrained execution |
| C10 | Content does not confer authority |
| C11 | Least capability, limits, and stop |
| C12 | Observable and protected evidence |
